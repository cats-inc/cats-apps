# Terminology

| Term | Meaning in Cats Apps |
|------|----------------------|
| App | Installable utility such as Usage |
| Product | Platform-level experience such as Chat, Work, or Code |
| App Package | Versioned manifest and built executable/static assets |
| App SDK | Public host contract owned by cats-platform |
| Catalog | Available apps/versions and their downloadable artifact metadata |
| Registry | Host-owned record of locally installed versions and lifecycle state |
| Desktop bundle | Pinned set of compatible app artifacts included in a Desktop release |
| Execution usage | Tokens/cost observed while work executes through runtime |
| Account quota | Provider-reported allowance or consumption for an account and window |
| Incident / cooldown | Runtime-observed failure or execution restriction, not a quota balance |
| Coverage | Which activity and time range an observation actually represents |
| mbf | Merge Bootstrap Files: reconcile pending *.bootstrap proposals |

Repository skills guide coding agents; they are separate from installed Cats App
capabilities. Optional A2A/MCP references are not a claim of implemented servers.
